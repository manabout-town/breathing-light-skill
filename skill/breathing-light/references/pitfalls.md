# 실제로 밟은 함정 (align-pilates, 2026-09-17)

## 1. 캔버스가 히어로 위쪽 일부만 덮음
`position:absolute; top:0; bottom:0`만 주면 canvas는 대체 요소라 **기본 비율(300×150 = 2:1)** 로 높이가 정해진다.
폰(390px)에서 높이 195px만 칠해졌다. → `height:100%` 명시. `verify.mjs`가 캔버스 높이 = 히어로 높이인지 검사한다.

## 2. 인트로 대기 중 가운데에 흰 원이 비침
구멍 마스크를 `transparent var(--hole), #000 calc(var(--hole) + 120px)`로 쓰면 hole=0일 때도 가운데 120px이 반투명 →
뒤 페이지가 비쳐서 "빛나는 원"처럼 보인다. 조명 문제로 착각하기 쉽다.
→ 흐림 구간을 구멍 **안쪽**으로: `transparent calc(var(--hole) - 120px), #000 var(--hole)`.

## 3. 붙였는데 "바뀐 게 없다"
밝은 바탕에서 빛 대비를 소심하게 잡으면 켠/끈 차이가 거의 없다. 1차 값(base .93 / shade .878)은 실패,
현재 warm 프리셋(base .90 / shade .82, leaf .22)에서 확실히 보였다. **켠/끈 스크린샷 비교를 반드시 할 것.**

## 4. 진행이 화면 주사율에 따라 빨라짐
프레임마다 `progress += x` 하면 120Hz 화면에서 2배 빨리 끝난다. 모든 애니메이션은 `performance.now()` 경과 시간 기준.

## 5. 헤드리스 캡처 타이밍이 안 맞음
playwright + swiftshader WebGL은 스크린샷 한 장에 1초 가까이 걸려 "0.3초 컷"이 이미 인트로가 열린 뒤로 찍힌다.
→ `getAnimations()`로 멈추고 `currentTime`을 옮겨 찍는다(verify.mjs 방식). 실제 브라우저에서도 같은 방법이 된다.

## 6. 짧은 클래스명 충돌
`.line`, `.sec` 같은 이름은 다른 컴포넌트와 겹친다(웹마켓에서 버튼이 깨짐). 이 스킬은 전부 `bl-` 접두사를 쓴다 — 유지할 것.

## 7. 인라인했더니 스크립트가 통째로 죽고 인트로가 안 닫힘
JS 파일 내용을 HTML `<script>` 안에 붙일 때, 파일 안(주석 포함)에 닫는 script 태그 문자열이 있으면 거기서 태그가 끝나
`SyntaxError` → `BreathingIntro`가 정의되지 않아 **인트로가 영원히 안 열린다**(keyforge, 2026-09-17).
→ 인라인 후 각 script 블록을 `node --check`로 검사. 인트로 CSS에는 JS가 죽어도 6초 뒤 자동으로 걷히는 안전장치가 있다.

## 기타
- 탭이 백그라운드면 rAF가 멈춰 배경·인트로 타이머가 늦게 시작된다. 정상 동작.
- `@property`(--bl-hole 전환)는 Safari 16.4+. 미지원 브라우저는 구멍 없이 opacity 페이드로만 사라진다(깨지지 않음).
- 히어로 아래 경계는 캔버스 하단 20% 마스크로 페이드 — 없으면 바탕색 차이로 선이 생긴다.
