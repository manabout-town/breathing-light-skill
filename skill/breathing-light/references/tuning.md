# 프리셋 · 조절 기준

## 프리셋 고르기 — 사이트 배경색에 가장 가까운 것

| preset | 바탕 느낌 | 어울리는 업종 | 글씨 | 인트로 방 색 제안 |
|---|---|---|---|---|
| `warm` | 밝은 웜 베이지 (#f3f1ec 계열) | 필라테스·요가·카페·리빙 | 진한 글씨 | 기본값 그대로 |
| `linen` | 더 밝은 린넨 | 웨딩·꽃집·갤러리 | 진한 글씨 | `--bl-room-1:#2b2824` |
| `mint` | 서늘한 민트 그레이 | 치과·클리닉·스킨케어 | 진한 글씨 | `--bl-room-1:#1f2624; --bl-room-2:#111615; --bl-glow:220,245,235` |
| `dusk` | 해질녘 짙은 갈색 | 바·와인·호텔 라운지 | **흰 글씨** | `--bl-room-1:#120f0c; --bl-room-2:#070605` |

`dusk`는 인트로 방과 히어로가 둘 다 어두워 "열리는" 대비가 약하다 → `--bl-glow`를 더 따뜻·밝게(255,200,150), `strength` 1.1.

직접 색을 줄 때: `base`(바탕) → `shade`는 base보다 0.06~0.1 어둡게 → `sun`은 거의 흰색에 사이트 온도(웜/쿨)만 살짝.
배경 순백(#fff)·순흑(#000)은 피한다(web-craft-baseline 규칙).

## 세기 조절 기준

| 증상 | 조절 |
|---|---|
| 켠/끈 차이가 안 보임 | `shade`를 더 어둡게 → 그래도 약하면 `strength` 1.1~1.2 |
| 빛줄기가 글씨를 가림 | `strength` .7~.85, 또는 `angle:[1,-.62]`로 방향 반전 |
| 잎 그림자가 얼룩처럼 보임 | `leaf` .12~.16 |
| 너무 정신없음 | `sway` .5, `period` 10~12 |
| 모바일 발열 | `scale` .35 |

## 인트로 문구
기본 "들이마시고 / 내쉬고". 업종에 따라 바꿔도 된다(예: 꽃집 "피어나고 / 머물고", 호텔 "Arrive / Unwind").
두 줄 구조와 타이밍(전반 47% / 후반 47%)은 호흡 원과 맞물려 있으니 유지.
